## ✨ Features

- 🎨 **Modern Design** - Clean and smooth UI with beautiful animations
- 🥤 **Interactive Display** - PageView with Scale & Translate animations
- ☕ **Hot/Iced Toggle** - Elegant toggle between Hot and Iced options
- 🔢 **Quantity Selector** - Simple and effective (+/-) buttons
- 📐 **Size Selector** - S / M / L / XL with interactive feedback
- 💫 **Smooth Animations** - Fluid transitions using AnimatedContainer
